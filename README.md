# Online MCQ Quiz App

A full-stack MCQ Quiz Application built using:

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Features

- Topic-wise MCQ questions
- Dynamic question fetching from backend
- Score calculation
- REST API integration

## Run Backend

cd server
node server.js

## Run Frontend

Open client/index.html

## API Endpoint

http://127.0.0.1:8080/
